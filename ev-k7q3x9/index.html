機種の数字（選ぶと入る）

貸しメダルは店の表示どおりに（1,000円で46枚の店は1枚21.7円になり、期待値がはっきり下がる）。前兆は、当選してから当たりが始まるまでに回すゲーム数で、当たり1回ごとに必ずかかる（天井到達後も同じ）。0のままだと期待値が高く出る（資料では北斗の拳が最大32G、ミリオンゴッドが2〜24Gなど。平均は資料にない）。当たったらやめる前提（当たり後の引き戻しや上乗せは「平均獲得」に含めて入力）。初期値は例です。

打ち続けたときの期待値の条件

現金で買うメダルは1枚20円（46枚貸しなら21.7円）、流すときは交換率の価値。機械割は資料の値（技術介入をきちんとした前提のことが多い）。等価でない店で現金を足しながら打つと、設定6でもマイナスになることがある。

設定ごとの確率（1/〇）・機械割（割%）・店の配分

確率は機種の解析値（設定差のある要素）。空欄の設定（解析値がない）は外して計算。店の配分は「その店でその設定が入っている割合」の見込み（比なので合計は100でなくてよい）。初期値は設定1が半分の保守的な配分（均等にすると、何も分からない状態でも高設定を甘く見て期待値がプラスから始まる）。イベント日など高設定が多いと分かっている日だけ変える。初期値は例。回数が少ないうちは差がつきにくく、「まだ判断できない」と出ます。

数字は「その演出が出た変動が当たる割合（信頼度）」。タップで説明と資料のちがい。

演出の見方（どの機種にも共通）

保留の色は強さの順

白 < 青 < 緑 < 赤 < 金 < 虹（虹はほぼ全機種で確定）

色の順はだいたい共通だが、何%かは機種で大きくちがう（赤保留でも2割台の機種もある）。数字は上の機種別で見る。保留が変わる（白→赤など）のは、変わった後の色の強さで見る。

信頼度は掛け算しない

「赤保留40%」と「群50%」が両方出ても、当たる確率は 40%×50% でも 足し算でもない。強い演出は当たりのときに重なって出やすいので、重なるほど上がるのは確かだが、正確な値は資料の「組み合わせ」の数字でしか分からない。

演出で期待値は変わらない

当たりかどうかは、玉がスタートに入った瞬間の抽選で決まっている。演出はそれを後から「知らせる」だけ。激アツが外れても台の期待値は下がらないし、熱い演出が続いても上がらない。打ち続けるかどうかは回転率とボーダー（パチンコのタブ）で決める。

やめるときの注意

保留（たまっている抽選）が残っているうちは席を立たない。保留は打ったお金ですでに買った抽選なので、消化しきってからやめる。パチスロは、前兆中やCZ・ATの抽選中（ゲーム数がゾーンにかかっているときなど）にやめない。

パチスロの演出

AT機は、演出の強さ＝当選の期待度（前兆・CZの成功期待度）。ジャグラーなどのノーマル機は、GOGOランプが光れば必ずボーナス。レバーを叩いた瞬間に光る「先ペカ」、リールが止まった後に光る「後ペカ」があり、プレミア（音や光の変化）は確定やBIG濃厚の合図。
